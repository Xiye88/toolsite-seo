# 选词、证据与低成本立项

本参考用于“值得做什么、首版做到哪里”的决策。已有明确需求与验收基线时只检查新增假设，不重新跑完整研究。

## 1. 先把词还原成任务

记录：谁、在哪个国家/语言、遇到什么问题、希望拿到什么结果、结果会在哪里使用。随后读实际 SERP，区分操作工具、教程、平台服务、品牌下载、社区讨论等意图。

同一个词可能包含互不相同的任务。模型发布热度不自动等于在线生成器购买需求；“银行账户二维码”也可能需要持牌体系，不能靠给现有表单换标题满足。

最少检查：

- SERP 主体是什么页面类型，前列结果是否真正完成任务。
- 大品牌是否也提供免费即时工具，而非只提供注册型服务。
- 工具结果能否被搜索摘要完全替代，用户是否仍需要操作。
- 用户为什么会用这个产品：打印、批量、排错、格式转换等具体价值是什么。
- 目标国家影响哪些实际条件：语言、数字/货币格式、设备、字体、支付资格、服务可达性。

参数化的国家/语言搜索仍是一次样本；记录查询、时间、参数、可观察的位置影响。没有目标地区实体设备/IP时，不宣称做了全国稳定排名监测。

## 2. 证据台账

每项证据至少记录 `日期、对象、国家/语言、来源类别、指标口径、观察值、限制、决策用途`。原始资料可能有敏感信息，内部保存与公开总结分别处理。

| 来源 | 能支持 | 不能直接推出 |
| --- | --- | --- |
| 官方文档/产品公告 | 功能、资格、协议或政策在该时点的说明 | 市场需求、本站兼容或合规认证 |
| 实际 SERP/竞品操作 | 搜索意图、供给形态、所见排名和体验 | 稳定名次、竞品收入、后端能力 |
| 关键词工具估算 | 同口径候选词的相对比较 | 精确人数、本站流量、广告收益 |
| 用户截图/转述 | 提供新的调查线索与该截图所显示结果 | 已独立核实、当前仍有效 |
| Trends | 指定地区/周期的相对关注走势 | 月搜索人数；两张独立图的 100 可比 |
| 联想词/相关查询 | 候选需求与措辞 | 每个词都有量，或总量可相加 |
| 社区/访谈 | 痛点、替代方案和用户用语 | 几条讨论代表市场规模或付费意愿 |
| GSC/产品后台 | 本站该窗口的已记录表现 | 未显示条目等于不存在、未来必然增长 |

未知、无收录、N/A、空结果、抓取失败分别写清。API 失败可换公开页面/浏览器或请求最小导出；仍未取得就保留未知，不填零。付费取数先限定问题、预算与停止点，不用大批请求替代判断。

对数据冲突先核对地区、日期、查询/整站、点击/访问/PV、渠道和估算方法。不能把一个工具的词量和另一个工具的流量估算相除，制造点击份额；不能把未注明币种的 CPC 当 RPM。

## 3. 竞争判断

工具站有低权重竞品进入 SERP，是可能入场的信号；仍需查其页面用途、站龄、引用和品牌基础。平台子域的高 DR 可能来自宿主，不等于该页面独立权重。

避免：

- 用某个 KD 标签直接承诺前十或 N 天排名。
- 将工具推算的引用域门槛转成购买外链清单。
- 把竞品整站访问当单页、自然搜索或目标国流量。
- 仅因页面朴素、停留短就判断体验差；即时工具可能快速完成任务。
- 把已注册的精确匹配域名当作市场或收入证明。

优先找能用实际输出验证的差异：文件可用、打印清晰、手机操作顺畅、输入本地处理、解释准确。已有的“免费、无需注册”应当作供给基线，不能反复包装成独占优势。

## 4. 从机会到立项

按用户本轮目标比较：需求证据、任务完整性、替代品、实现/维护成本、外部依赖、获客未知、收入假设。无需为凑表格编一个综合机会分。

工具站示例：成熟浏览器库即可完成的生成任务，通常比需要按次付费 API、排队、远程存储与账户体系的任务更适合作为低预算实验。这是成本判断，不是通用市场优劣。

首版应写清：

1. 一个主要用户任务及可观察完成动作。
2. 最少输入、输出、错误状态和支持设备/语言。
3. 哪些数据必须离开浏览器，为什么；无需后端的部分继续本地处理。
4. 最小可信页面：工具说明、限制、隐私及可用联系渠道，依产品实际需要配置。
5. 明确暂缓：登录、批量、云存储、API、收费、广告等，只有有需求才纳入。
6. 验收方式、观察窗口、成本上限与下一轮决策。

域名购买或后台权限卡住时，先完成可迁移代码、正式域名配置点及构建；不要为等待一个外部条件停掉全部可做项。

## 5. 继续、缩减与停止

在投入前约定与项目规模相称的条件，具体阈值由目标和可得样本决定：

- 继续：任务确实可完成，有目标用户反馈/有效使用信号，维护与单位成本可承受。
- 缩减或换任务：SERP 意图与产品不符、关键工作依赖不可得、增值功能没有独立价值。
- 停止投入：无法提供安全有效输出、超预算且无可验证价值、必要商户/数据许可不满足。
- 延长观察：新站报表仍在处理、样本太少、已完成技术检查但暂无增长证据。延长观察不自动触发扩页。

记录假设、反证和复查条件。时间估算不是上线承诺，技术上线不是需求验证完成，需求存在也不是商业模式成立。

## 6. 变现只做有口径的算账

广告条件演算可用 `PV / 1000 × 页面 RPM`；每个变量标明假设/实测、地区、渠道与时间。订阅需要任务价值、价格接受、复用频率、合格收款方式及交付成本证据。不要以国家刻板印象替代验证。

低预算工具站可以先验证免费核心任务，不以广告审批或订阅作首版前提；后续收费需要独立验证和授权，不能回写成当初已经验证的付费需求。
